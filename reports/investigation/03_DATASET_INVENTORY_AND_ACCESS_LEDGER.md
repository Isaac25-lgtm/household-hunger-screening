# Dataset inventory and access ledger

The machine-readable version is in `03_DATASET_INVENTORY_AND_ACCESS_LEDGER.csv`. No credentials were requested, entered or stored, and no access requests or emails were sent.

| Dataset | Obtained? | Usable for | Barrier / note |
|---|---|---|---|
| Aggarwal et al. (2022) S1 Data | Yes (CC BY 4.0; checksum verified) | Baseline HHS analyses; extensions in this investigation | None |
| World Bank Malawi HFPS 2020–2024, v20 | Yes, supplied by you; checksum matches | External replication with a different instrument (FIES items 7/8); calendar-matched transfer tests; robustness; subgroups; second-contact rule | Public Use File terms: aggregates only, cite the dataset, no redistribution. No panel weights or PSUs. Round 1 coincides with both the pandemic onset and the first interview. Rounds 19–21 split into sample groups. |
| MIRA, southern Malawi (CRS/Cornell), monthly HHS | No | Would be the ideal same-instrument, month-level test | Not public. Smith et al. (2026) use 2,267 households over 39 months; a CRS–Microsoft paper states the data are not publicly available. Needs a data-sharing request, which I have not sent. |
| Malawi RFMS 2020–2025 | No | Monthly monitoring panel | Not public. Household overlap with MIRA (MIRA fed into RFMS) is unverified, so the two must not be counted as independent. |
| CRS MIRA, southern Madagascar | No | Possible | Only a general search; no access route identified; nothing verified |
| Myanmar MHWS rounds 1–6 (IFPRI, Harvard Dataverse) | No | HHS is reported in IFPRI notes; about 3 rounds a year | The Dataverse guestbook asks for the requester's identity, which I did not fill in on your behalf. HHS variables per round are unverified. The long gaps between 30-day recall windows limit any timing analysis. |
| Other LSMS-HFPS countries (Burkina Faso, Ethiopia, Nigeria, Tanzania, Uganda) | No | **Best route to a genuinely untouched, protocol-locked test** | Needs your Microdata Library login. Write and lock the protocol (candidate months from FEWS NET seasonal calendars) *before* downloading. |

**Independence.** The World Bank HFPS is independent of the Aggarwal sample: it is a national frame drawn from the Integrated Household Panel Survey 2019 (IHPS), not a set of rural trial villages. It also uses a different instrument. The Aggarwal Malawi villages could appear inside the national IHPS frame by chance, but there is no way to link them, and linking would breach the World Bank terms.
